Install on iPhone

  1. Host this HTML page on a trusted HTTPS website, then open it in Safari on the iPhone.
  2. Tap Generate .mobileconfig profile and allow the download.
  3. Open iPhone Settings. If prompted, open Profile Downloaded; otherwise go to General → VPN & Device Management.
  4. Review the profile details and install it only if you recognize the Cloudflare endpoint and want these DNS settings.
  5. To remove it later, go to Settings → General → VPN & Device Management, select the profile, and remove it.
Important: A downloaded profile is not the same as an installed profile. iOS may show different menu wording depending on its version. If the profile is rejected, don't bypass the warning; use Cloudflare's official 1.1.1.1 app or manual Wi-Fi DNS configuration instead.
